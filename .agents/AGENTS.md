# 🌿 Workspace Rules & Guidelines

## 🛡️ Git Workflow and Commit Rules

### 1. Main Branch Integration
* **Rule**: The latest working code must be integrated, tested, and kept in the **`main`** (or **`master`**) branch. 
* Avoid stale feature branches containing final implementations. All verified work must be merged into the primary branch.

### 2. Regular Push Mandate
* **Rule**: Every team member must push their progressive updates/code to the remote repository **at least once every 1 hour**.
* Continuous integration prevents complex merge conflicts and keeps the team synchronized in real-time.
