# 🎬 EcoSphere — Demo Recording Script

> **Duration:** 6–8 minutes  
> **Format:** Screen recording with voice narration  
> **Setup Required:** Two browser windows (Manager + Employee accounts)

---

## Pre-Recording Checklist

- [ ] Docker running → `docker-compose up -d`
- [ ] Server running → `cd server && npm run dev` (port 5000)
- [ ] Client running → `cd client && npm run dev` (port 3000)
- [ ] Database seeded → `npm run db:seed`
- [ ] Browser 1 ready: http://localhost:3000 (will login as Admin/Manager)
- [ ] Browser 2 ready: http://localhost:3000 (will login as Employee)
- [ ] Clear browser downloads folder (CSV export demo)
- [ ] Screen recording tool ready (OBS / built-in)

### 🕐 6:15 – 6:45 | Architecture & Technical Depth

> *"TypeScript end-to-end. React 19 with Vite on the frontend, Express with Prisma ORM on the backend. PostgreSQL 16 running in Docker."*

> *"Key services: a Scoring Engine that computes weighted ESG scores from real data. A Forecast Engine using linear regression for emission projections. A Badge Award Engine that fires after every XP mutation. A Nudge Engine that generates behavioral recommendations. And an SLA Watcher CRON job monitoring compliance deadlines."*

## 📌 Key Points to Emphasize in Recording

| Point | Why It Matters |
|-------|----------------|
| **Real-time updates** | Visually demonstrates Socket.IO in action — judges see it live |
| **Gamification loop** | Challenge → Approve → XP → Badge → Leaderboard — a complete cycle in 30 seconds |
| **Concurrency safety** | Shows production-grade thinking (row-level locking) |
| **Forecast engine** | Demonstrates algorithmic depth (linear regression, anomaly detection) |
| **SLA automation** | Shows background processing maturity (CRON jobs) |
| **Two-screen demo** | Proves real-time sync between different users |
| **Impact translator** | Makes the solution emotionally resonant ("847 trees saved") |

## 🚨 Backup Plan — If Something Breaks During Recording

| Issue | Quick Fix |
|-------|-----------|
| Server crash | Restart: `cd server && npm run dev` |
| Database empty | Re-seed: `npm run db:seed` |
| Socket not connecting | Refresh both browser tabs |
| CSV not downloading | Check browser download settings / permissions |
| Score rings not animating | Hard refresh (Ctrl+Shift+R) |
